COUPRESHFUND WEB FRONTEND - WORK SUMMARY
========================================

Project
-------
CouPreshFund is a student-focused financial empowerment frontend built with
React, React Router, and Vite. This summary records the frontend work completed
through November 1, 2026.

- Added a profile summary at the end of onboarding.

BACKEND INTEGRATION AND CURRENT DATA STATUS
-------------------------------------------
- The frontend integrates with registration, login, authenticated student
  restoration, onboarding persistence, dashboard summary, and contribution
  endpoints.
- Authentication tokens are stored in browser local storage and attached to
  authenticated API requests. The current student and saved onboarding profile
  are restored after a page reload; dashboard routes require authentication.
- Onboarding school, graduation goal, purpose, and savings plan are saved when
  setup is completed.
- The Home and My Money views load saved goals, contribution totals, progress,
  and recent self-reported contributions from the backend.
- Students can record and list self-reported savings. This does not initiate
  or verify a payment.
- Budgets, learning progress, opportunities, points, and guardian invitations
  remain frontend-defined and are not persisted by backend APIs.
- Removing UI language that called content a demo or preview changed only
  labels and messages. It did not connect these product screens to live
  backend data.
